## 已实现

完整的先到 3 胜单机大局：五场地、公开牌桌、逐目标最少张数换牌、吸牌、一次弃牌、控制区整场限用一次、先补牌后洗牌、自动卡住和比牌、败者先手、小局及大局平局。战区初始牌没有额外限制。

浅色牌桌配合触屏点选；手机选牌后显示固定底部确认栏，控制区可展开查看和选牌。支持随机种子、自动存档恢复、三种 AI、建议、可接管代打、可选音效和回合记录。没有网络对战、下注、肉鸽或额外牌组。

实验室提供 Worker 批量模拟、种子和策略设置、停止、CSV/JSON 导出。命令行模拟采用同一套引擎。

## 复核入口与待讨论项

Q1–Q6 均保留为设计讨论。原文的【默认】项按原文实现，不引入主动跳过、认输提前结算或控制区换牌等规则。卡住时自动跳过，小局间仍手动继续，以便查看结算。

每次 main 推送由 GitHub Actions 测试、构建，再部署 Pages。页面为纯静态产物；浏览器存档只保留在本机当前站点，没有账号同步。自动化执行后端在本次任务中超时/额度失败，由主代理直接完成所有实现；失败日志位于忽略的 `.local/engine-run-01/`，不上传仓库。
