## 1. 诊断：v0.1 为什么无趣

### 1.1 数据

| 观察 | 数据 | 说明 |
|---|---|---|
| 策略 AI 对贪心 AI | 48.1% : 51.9% | 认真规划没有比"每步取最高牌型"更强。**决策杠杆接近零。** |
| 弃牌使用率 | 90,020 手牌中 90,020 次弃牌 | 弃牌不是选择，是固定步骤。 |
| 最终牌型 | 两对 30.9%，葫芦 27.0%，同花 12.7%，顺子 11.0%，三条 3.1% | 双峰：要么卡在两对，要么冲到葫芦。胜负像抽签。 |
| 打满五局 | 59.4% | 决胜局多是 n=2 对 n=2，运气占比最高。 |
| 上局胜者续胜 | 43.2% | 拉平成立，但"赢了就变弱"削弱赢的爽感。 |
| 小局 / 大局平局 | 0.08% / 0.02% | **平局不是实际问题。** 五局三胜的问题是每局分量恒定、没有高潮。 |

### 1.2 对原模型描述的修正

原描述是"带公共随机源的 MDP + 完全信息单调爬山"。准确地说，它是**完全信息 + 机会节点**的博弈，和西洋双陆同类。"能算出最优解"不是病根：双陆同样能算，靠倍数骰至今仍有深度。病根是三个结构性质：

1. **解耦**：两人各自在牌型格上单调爬升，唯一交集是共享牌库。对手局面几乎不进入你的决策，"规划"等于"把自己爬高"，贪心已接近最优。
2. **没有停止决策**：小局在双方卡住时强制结束，玩家从不面对"收手还是继续"。
3. **赌注恒定且二元**：每局只值 1 分，没有"这一局特别重要"的时刻。

### 1.3 推论：暗牌和赌注必须做成一个系统

- **只加暗牌**：看不到对手的牌，但没有决策依赖它。结果是更看不清的抽签，运气感更重。
- **只加赌注**：明牌上的加注、跟注可以精确算胜率，是纯数学题（双陆式），有深度但没有心理博弈。
- **两者结合**才有扑克的核心：决策收益取决于对手的隐藏信息，对手的行为（加注、撤退、换牌张数、弃了什么）又部分泄露这份信息。

设计原则：**每一份隐藏信息都要有一个依赖它的决策，以及一条部分泄露它的通道。**

## 2. v0.3 底层模型

### 2.1 形式描述

v0.1：状态全公开（除牌库顺序）；战区牌型 $X_i(t)$ 单调不降；小局收益 $\operatorname{sign}(X_A(T) - X_B(T))$，$T$ 为双方卡住的时刻（外生）；先到 3 胜，赢家减少一个普通场地。

v0.3：**部分可观测随机博弈 + 赌注过程**。

- 观测 = 公开部分 + 本人私有部分（普通场地、战区暗牌）；
- 爬山规则不变，$X_i(t)$ 仍单调不降，但对手只能看到一部分；
- 小局赌注 $v$，可加注到 $2v$，被加注方立即跟注或撤退；
- 撤退方付 $v$；亮牌败者付 $m \cdot v$；
- 筹码归零击倒；打满 5 个战区后比筹码。

### 2.2 四层决策

| 层 | 内容 | v0.1 | v0.3 |
|---|---|---|---|
| L1 资源层 | 吸牌、换牌、弃牌怎么爬 | 有，但贪心近似最优 | 保留，不改 |
| L2 信息层 | 哪张暗置、换出什么亮进牌河、何时暴露意图 | 无 | 新增 |
| L3 赌注层 | 何时加注、跟还是撤 | 无 | 新增 |
| L4 战役层 | 筹码节奏、拉平、底注递增 | 先到 3 胜 | 重做 |

L1 不改，原有吸牌、换牌、补牌、洗牌、卡住的规则与证明基本原样保留。新增内容只在可见性和赌注上，实现风险小。

### 2.3 跟注阈值（调参把手）

对手把赌注从 $v$ 加到 $2v$：撤退得 $-v$；跟注打到亮牌、胜率 $p$，期望 $(2p-1)\cdot 2v \cdot m$。跟注条件：

$$
p \ge \frac{2m-1}{4m}
$$

$m=1$ 时为 25%（与双陆倍数骰接受点相同），$m=2$ 时为 37.5%。$p$ 依赖对手暗牌，无法精确计算，只能推断。阈值越高，撤退越常见，诈唬越有效。**$m$ 是调节心理战强度的主旋钮。**

## 3. 参考作品与取舍

| 作品 | 机制 | 启发 | 取舍 |
|---|---|---|---|
| 梭哈（五张 1 暗 4 明，七张 3 暗 4 明） | 部分明、部分暗，按发牌节奏下注 | 战区 3 明 2 暗，从明牌推暗牌 | 采用：战区暗位 |
| 立直麻将 | 手牌暗，舍牌公开成牌河；立直＝押注并锁手 | 换出、弃掉的牌亮出后再回牌库 | 采用牌河；立直留 v0.4 |
| Marvel Snap | 三路比拼；Snap 翻倍；末回合自动翻倍；撤退只输当前立方；上限 8 | 每人每局一次加注、亮牌翻倍、撤退付当前赌注、上限 8 | 采用：核心赌注模型 |
| 西洋双陆倍数骰 | 加倍后对方立即接受或认输 | 加注要求立即表态；阈值可推导 | 采用：立即应答 |
| 德州扑克 | 自由下注、位置、河牌下注轮 | 牌面确定后的最终表态是高潮；后行动有位置优势 | 采用最终表态轮；不采用自由下注额 |
| Battle Line / Schotten Totten | 多条战线摆牌型，可证明必胜时提前认领 | 与战区同构；提前结算需求（v0.1 Q4）由撤退解决 | 参考 |
| 昆特牌 | 三局两胜；故意输一局保存手牌 | 拉平在筹码制下可能诱发"故意输小局" | 规避：只有亮牌胜才占领 |
| Inscryption | 天平伤害差到 5 获胜 | 赢多少比赢几局重要 | 采用思想：筹码 |
| Buckshot Roulette、Liar's Bar | 已知构成、未知顺序；每次表态有代价；对手表演 | 沉浸来自赌注可见、节奏停顿、亮牌仪式 | 表现层 |
| Balatro | 德州牌型 + 肉鸽倍率 | v0.1 Q5 的肉鸽方向 | 留后 |

## 4. AI 要求

### 4.1 信息隔离（硬约束）

- 引擎提供 `viewFor(game, player)`，只含公开信息与该玩家的私有信息。UI 和 AI 只读视图。
- 测试：把对手的暗牌、手牌与牌库中的未知牌任意互换（公开事实不变），AI 决策必须不变。
- 诈唬随机性来自"公开状态 + 本人私有牌"的哈希，不读游戏 RNG，不用 `Math.random`。

### 4.2 基线策略

- **爬山**：沿用现有策略 AI。新增"首次吸牌选哪张暗置"：优先暗置最暴露路线的牌（对子成员、第三张同花色、顺子连接牌）。
- **胜率估计**：从本人视角的未知牌中抽样填入对手暗牌和手牌，用贪心推演到亮牌，统计 $p$。过滤与公开事实矛盾的样本。
- **下注**：$p$ 高于加注阈值时加注，$p$ 很低时按诈唬频率 $b$ 诈唬；$p \ge \frac{2m-1}{4m}$ 时跟注，按性格偏移。
- **性格**：稳健（$b$ 低、跟注偏紧）、均衡（默认）、诈唬（$b$ 高）。

### 4.3 对照策略（只用于模拟）

- 透视：读取对手真实暗牌和手牌，衡量隐藏信息的价值。
- 跟注站：永远跟注，从不加注，不撤退。
- 随机下注：表态随机，爬山与均衡相同。

## 5. 模拟验证

### 5.1 深度是否出现（最重要）

| 指标 | 含义 | 目标（假设） |
|---|---|---|
| 均衡对跟注站的大局胜率 | 赌注决策的杠杆 | ≥ 60%（v0.1 策略对贪心为 48%） |
| 透视对均衡的胜率 | 隐藏信息的价值 | ≥ 60%；接近 50% 说明暗牌无人在乎 |
| 撤退胜中撤退方本可亮牌赢的比例 | 诈唬成功率 | 10%–25% |

### 5.2 节奏与情绪

| 指标 | 目标（假设） |
|---|---|
| 击倒率 | 30%–50% |
| 平均小局数 | 3.5–4.5 |
| 每小局撤退率 | 30%–50% |
| 第 2 小局后筹码落后方最终获胜 | 25%–40% |
| 领先方在后两局开局即撤退 | 越低越好；过高需加陡底注 |
| 首轮先手大局胜率 | 47%–53% |
| 大局平局 | 0（断言） |

### 5.3 参数扫描

手牌公开（纯梭哈式）对私有；战区暗位 0 / 1 / 2；$m$ = 1 / 2；底注 `[1,1,1,1,1]` / `[1,1,1,2,2]` / `[1,1,2,2,4]`；起始筹码 8 / 10 / 12。v0.1 规则保留为对照组。

## 6. 表现层要点

遵守仓库 `DESIGN.md` 和一屏可玩的约束。

- **筹码要有实体**：双方筹码堆与桌心赌注堆。加注时筹码推入桌心，翻倍有明显的节拍和音效。
- **加注是一个停顿**：AI 加注后只给"跟注 / 撤退"，显示代价（撤退付 $v$，亮牌输付 $m \cdot 2v$），不塞说明。
- **亮牌仪式**：最终表态后，暗牌逐张翻开，先翻对手的；牌型落定后再结算筹码。
- **撤退不亮牌**：牌背朝上滑回牌库，强化"你永远不知道他有没有"。
- **牌河**：换出、弃掉的牌明牌飞向牌库（复用 `CardFlights`），本小局亮出过的牌可在收起区域回看。
- **对手性格**：开局一句话或头像状态区分，不显示数值。
- **击倒**：给整场最强的反馈，区别于打满 5 局的点数胜。

## 7. 后续版本候选（不进入 v0.3）

- 立直式锁定加注：加注时宣布锁定战区，换取 ×3。给"停手"一个理由。
- 反加：被加注时直接用自己的加注权反加。
- 认领：参考 Battle Line，可证明必胜时提前认领。
- 肉鸽层：Balatro 式道具，例如"控制区换牌""偷看一张暗牌"。
