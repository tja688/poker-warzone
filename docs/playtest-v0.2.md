# v0.2 体验重构验收

日期：2026-11-07。规则仍为 [v0.1 原案](rules-v0.1.md)。

本轮将原来的网页式侧栏与长页面改为固定窗口牌桌；删除主界面的宣传标题、种子设置、代打、建议、日志、研究导航。模拟功能保留在 `?lab`。保持已有规则存档兼容。

## 已验证

- 规则测试 17 项通过，含 243 场跨策略配对、不变量与隐藏信息隔离。
- TypeScript 与 Vite 生产构建通过。
- 浏览器 6 个场景通过：多尺寸完整可视、吸牌与续局、帮助暂停 AI、重开/音效开关、换牌/弃牌/控制区、完整对局与再开、键盘/减少动态、模拟导出与停止。
- 9 种窗口：1440×900、1366×768、1024×768、768×1024、390×844、375×667、320×568、844×390、667×375。检查了文档滚动尺寸与卡牌/关键控件边界，并看过实际截图。
- 整场测试通过真实按钮逐次操作，非 UI 代打；结算后进入下一战区，最终到达三胜，再次开局。
- 通过测试页面没有运行时异常。浏览器为 Windows Edge/Chromium；未使用 iOS Safari 真机验证，音色未做人工听感评定。

## 可维护性

`engine.ts` 保留规则，策略迁入 `ai.ts`；界面按选择、场地、操作、回合控制、飞牌、声音、帮助和结算文案拆分。加入 `AGENTS.md` 和 `architecture.md`，记录规则边界、草稿生命周期、动画身份、旧存档与下一版修改入口。

## 范围

本轮是玩法测试体验改造。没有加入新规则，也未重新宣称平衡性或 AI 强弱。原案 Q1–Q6 仍是下一轮规则讨论，不因界面简化而自行作出设计决定。
