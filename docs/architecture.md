## 状态如何走

1. `createGame(seed)` 建局；`store` 自动载入有效旧局，否则建立新局。
2. `legalActions(game)` 枚举当前玩家所有合法操作，是 UI 和 AI 的共同边界。
3. `useSelection` 只维护草稿，保留目标牌型、换入和换出牌。预览不会写回 game。
4. `GameTable.perform` 同步检查重复提交锁及预期状态引用；`store.act` 调用纯函数 `applyAction`，验证断言后保存。
5. 引擎会推进补牌、洗牌、自动卡住和结算。UI 等待表现节奏结束后才允许下一步。
6. AI 仅在 `play` 阶段、AI 回合且没有弹窗暂停时安排定时器。effect 清理定时器；执行时再次验证状态引用，旧回调不能污染新局。
7. `roundOver` 由玩家点击进入下一战区；`finished` 只提供重开。

`TurnView` 的 key 是种子、小局、回合编号、阶段。任何真实状态推进都会丢弃旧草稿，避免旧选择被带入新局。`LayoutGroup` 在它外层保持稳定，卡牌用实际牌 ID 在场地和战区间衔接；预览与弹窗里的副本不使用共享 ID。

## 原案中容易误改的约束

- 所有普通场地和控制区都公开。只有牌库顺序未知。
- 换牌对每个目标牌型分别求最小换牌张数，并且等级严格提高。初始牌可换出。
- 普通牌只能在本人下回合开始补满；先补牌，后洗牌。换出/弃掉的牌回到底部。
- 一次吸牌可混用普通牌与多个控制区，但每个控制区整场限取一张。
- 只有双方都无合法操作才比牌；不可主动空过或提前结束。
- 平局双方各得一胜；同时到三胜则整场平局。
- 控制区及其中剩余的牌保留到整场结束。

`engine.ts` 负责这些规则；`ai.ts` 只给合法操作打分。AI 的信息隔离测试会改变牌库、种子和 RNG，要求同公开局面的决策保持一致。

## 第二版、第三版怎么接

先在新的规则文档中写出具体差异、一个例子和验收结果。保留 `rules-v0.1.md` 作为原案。然后按受影响的规则边界修改实现与用例；数值确实需要多个版本共存时，再引入显式的规则配置/版本标识，避免现在预设尚不存在的肉鸽系统或扩展插件。

例如“允许控制区换牌”同时影响：`legalActions` 的来源枚举、`applyAction` 的控制区使用处理、断言、AI 成本、UI 可选来源。只放开前端点选会被规则拒绝，也会让模拟和试玩不一致。

例如“战区张数改为六张”不是改一个 CSS 常量：牌型算法、操作容量、卡住证明、牌库下限和布局都要重新验证。UI 中当前有固定五槽位，与现行规则一致。

## 存档

局状态使用 `poker-warzone-v1`，AI 风格旧设置使用 `poker-warzone-ai-v1`，声音使用 `warzone-sound`。v0.2 只重构界面，保留已有规则存档。自动载入后会执行 `assertInvariants`，存档损坏时开新局；浏览器拒绝存储不影响本次游玩。

未来规则或数据结构不兼容时，选择明确迁移或新的 SAVE_KEY，并解释旧局如何处理。不要让旧局在新规则下悄悄继续。草稿、音频上下文、动画坐标及 AI 定时器都不属于存档。

v0.3 使用单独的 `poker-warzone-v03`。读档若带有筹码字段、阶段不是行动或结算，或没有 `core`，就新开一局 v0.3，不把 `poker-warzone-v1` 拿来继续。规则选择记在 `poker-warzone-rules`。切换规则只改当前显示的牌桌，两份进行中的存档都留着。当前 v0.3 没有赌注，胜负是先到三胜，盖牌保留。

## 适配与验收

牌桌使用 `100dvh` 三行布局：页头、可用高度内的桌面、操作区。桌面是 size container，牌尺寸由 `cqh` 与屏宽共同限制。短横屏将资源牌移到左右两侧。只有帮助等弹窗和独立研究页面可内部滚动。

浏览器测试覆盖 1440×900、1366×768、1024×768、768×1024、390×844、375×667、320×568、844×390、667×375。它同时断言文档尺寸和卡牌/按钮边界，不能仅以 overflow:hidden 作为通过依据。截图在 `.local/screenshots`，应人工看文字和控件是否重叠。

自动测试使用真实按钮操作吸牌、指定换牌组合、弃牌、控制区取牌、整场对局、重开、键盘、减少动态效果以及模拟导出/停止。引擎套件包含 243 场固定种子策略组合和 52 张牌守恒断言。截图与自动通过不等于人类已验证玩法乐趣或 AI 强弱。

发布通过 `.github/workflows/pages.yml`；main 推送触发单元测试、构建和 Pages 部署。本机 E2E 默认用 Edge；CI 环境可用 `PLAYWRIGHT_CHANNEL=chromium` 和已安装的 Playwright Chromium。
