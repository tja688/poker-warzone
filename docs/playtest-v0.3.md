# v0.3 试玩测量

当前线上规则没有赌注。胜负是先到三胜，盖牌保留。下面的扫描描述的是更早的筹码草案，测量表还是空的，不能当成现在这版的结果。

`npm run scan:v03` 把 108 个配置各写成一份 JSON，目录是 `docs/simulation-v0.3/`。

每一份有三组对局。每组 2000 场，种子是 `scan-v03`。

- 均衡对跟注站
- 透视对均衡
- 均衡对均衡

配置是手牌私有或公开、暗位 0/1/2、倍数 1/2、底注 `1,1,1,1,1` / `1,1,1,2,2` / `1,1,2,2,4`、起始筹码 8/10/12。封顶保持 8。

抽样数默认 8。脚本先用最重的一格跑 20 场。这一格是私有手牌、暗位 2、倍数 2、底注 `1,1,1,1,1`、起始 12、透视对均衡。若 8 次抽样让单场平均慢于 80ms，就把抽样数减半，直到平均不慢于 80ms 或降到 1。探测写在同一条日志里。

同一套开关也可以单次运行。`npm run simulate -- --rules v0.3` 接受 `--a`、`--b`、`--games`、`--seed`、`--samples`、`--privateHands`、`--hiddenSlots`、`--multiplier`、`--antes`、`--startingChips`、`--out`。省略 `--rules` 或写成 `v0.1` 时，仍走原来的经典模拟，用不上的开关被忽略。

## 指标怎么算

分母只含完整结束的场。这些场的筹码合计等于起始筹码的两倍，并且有唯一胜者。筹码合计不对，或没有胜者，计入 `assertionFailures`，不进入比率。大局平局记在 `draws`，必须是 0。没有胜者算失败，不记成平局。

| 指标 | 算法 |
| --- | --- |
| 座位 0 大局胜率 | `wins[0] / completed` |
| 撤退胜里，撤退方本来能亮牌赢的比例 | `retreatWouldWin / retreats` |
| 击倒率 | `knockouts / completed` |
| 平均小局数 | `rounds / completed` |
| 每小局撤退率 | `retreats / rounds` |
| 第 2 小局后筹码落后者仍赢下整场的场次占比 | `trailerWins / completed` |
| 领先方在第 4 或第 5 局开局就撤退 | `leaderOpenRetreats / leaderOpenChances` |
| 首轮先手大局胜率 | `firstStarterWins / completed` |
| 大局平局 | `draws`，必须为 0 |

第 2 小局后双方筹码相同，或整场不到两小局，这场不是落后翻盘。第 4、第 5 局只有领先方自己先说话时才计入 `leaderOpenChances`。筹码相同，或领先方不是该局先手，这一局不进分母。开局就撤退指领先方的第一手是撤退。

撤退方是否本来能赢，用撤退当下双方战区的牌比较，含扣着的牌。这个比较只进计数，不写回牌桌。

击倒是结束时有一方筹码为 0。筹码赛完是打满 5 个小局且双方都还有筹码。
